# 팬 니즈 조사 (2026-09-17)

조사 방법: WebSearch 예산 소진으로 curl + Playwright(구글 렌더링) 직접 수집.
주 출처는 **디시인사이드 농담곰 마이너 갤러리(`nongdamgom`)** — 글 번호 10만 8천대, 한국 나가노(치이카와/농담곰) 팬덤의 사실상 메인 커뮤니티.
보조로 치이카와 마이너 갤러리(`chiikawa`, 글 520여 개), 더쿠(구글 색인 스니펫), 네이버 블로그/인스타(구글 색인), 공식 사이트 직접 확인.

> 더쿠(theqoo.net)는 curl·Playwright 모두 403으로 직접 열리지 않아 **구글에 색인된 제목·스니펫**으로만 인용했습니다. 해당 인용에는 `(구글 색인 스니펫)` 표기를 붙였습니다.

### 정리 — 아무도 채우지 않은 빈틈

1. **한국어 통합 발매·재입고 캘린더** — 일치마/중치마/용치마/대원/팝업을 한 줄에 놓고 "언제 한국에서 살 수 있나"에 답하는 곳이 없습니다.
2. **재입고 알림** — 공식몰이 재입고 목록을 전날 숨기고, 알림 기능이 없습니다. 지금은 갤 속보와 "특파원"이 대체하고 있습니다.
3. **검색 가능한 가품 DB** — 팬 1인 노션이 사실상 유일하고, 자주 죽고, 신상 반영이 늦습니다.
4. **시세 이력** — 커뮤니티가 질문을 금지해서 시세 감각이 구전으로만 존재합니다. 체결가 기반 데이터가 전혀 없습니다.
5. **팝업 실시간 대기/재고** — 현장 재고 질문도 금지라 매장 전화가 최선입니다.
6. **쿠지 구성·확률·예상 배송비 계산** — 일본 팬 계정 링크와 개인 실비 후기에 의존합니다.

## 확인 못 한 것

- **더쿠 원문 전문** — theqoo.net이 curl·Playwright 모두 403(Cloudflare 추정). 구글 색인 제목·스니펫으로만 인용했고, 게시글 번호가 스니펫에 드러난 2건만 직접 URL을 확보했습니다. 나머지는 `theqoo.net/ktalk`, `theqoo.net/an` 수준까지만 특정됩니다.
- **네이버 카페 cafe.naver.com/chiika** — 로그인 벽으로 접근 불가. 존재 여부·규모 미확인.
- **네이버 통합검색** — JS 렌더링이라 curl로 본문 수집 실패. 블로그/인스타 인용은 구글 색인 스니펫 기준입니다.
- **아카라이브·루리웹·여성시대** — 이번 조사에서 치이카와 관련 유의미한 집적지가 확인되지 않았습니다. 농담곰 갤러리가 압도적이라 우선순위에서 제외했습니다(추가 조사 여지 있음).
- **중치마 공식 도메인** — 커뮤니티·인스타·블로그·번개장터 모두 "중국 치이카와 마켓 = 공식"으로 일치하나, **중국 측 공식 URL 자체는 확인하지 못했습니다**(`chiikawamarket.cn` 등은 국내에서 연결 실패). 타오바오/티몰 공식 스토어 형태로 운영되는 것으로 보입니다 **(추정)**.
- **X(트위터) 원문** — 로그인 벽으로 직접 열지 못하고, 갤에 인용된 링크와 구글 색인으로만 확인했습니다. `@chiikawa_info`의 쿠지 확률 게시물 원문은 미확인.
- **가품 노션 실물** — 현재 접속 가능한 URL을 특정하지 못했습니다(갤 내 링크가 여러 차례 이사·폐쇄됨). 존재와 운영 방식은 다수 글로 교차 확인했습니다.
- **정확한 빈도 수치** — dcinside 검색은 결과 총계를 제공하지 않아 1~3페이지 실측으로 대체했습니다. "58건"은 3페이지 상한에 걸린 값이며 실제로는 더 많습니다.
- **쿠지 "뭐가 남았는지 모름"** — 일본 오프라인 이치방쿠지 잔여 재고 관련 한국어 불만은 이번 조사에서 직접 인용을 찾지 못했습니다. 대신 오프라인 매장·팝업 재고 불투명 불만이 강하게 나타났습니다.
