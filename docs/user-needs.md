# 팬 니즈 조사 (2026-09-17)

> 작성 중 (중간 저장). 주 출처: 디시인사이드 농담곰 마이너 갤러리(`nongdamgom`) — 한국 치이카와 팬덤의 사실상 메인 갤러리. 치이카와 마이너 갤러리(`chiikawa`)는 글 수 500여 개로 소규모.

## 용어 정리 (조사 중 확인)
- **일치마** = 일본 치이카와마켓 (공식 chiikawamarket.jp)
- **중치마** = 중국 치이카와마켓
- **용치마** = 용산 치이카와마켓 (한국 오프라인 매장)
- **갤주 / 부갤주** = 갤러리 주인장, 즉 치이카와 / 농담곰을 가리키는 은어
- **마코** = 마스코트 인형, **누이** = 봉제인형
- **머원 / 태원** = 대원미디어(정발사) 비꼬는 표현
