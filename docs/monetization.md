### 2-2. 수수료·운영 방식

**핵심 구조: 1차금 / 2차금 분할 입금** (사실상 전 공구 공통)

```
1차금 = 상품 가격 (엔화 × 적용 환율)   ← 공구 마감 시 선입금
2차금 = 해외배송비(해배비) ÷ 참여인원(1/n) + 국내 택배비  ← 물건 도착 후 정산
```

**수수료는 별도 항목이 아니라 "적용 환율"에 숨어 있다.** 실제 관찰된 표기:
