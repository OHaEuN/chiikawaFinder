### 1-1. 목록통관 대상 여부 (캐릭터 굿즈)

목록통관 = 통관목록 제출만으로 수입신고 생략, 관세·부가세 미부과.
조건: 개인 자가사용 + 물품가격 150불 이하(미국발 200불) + 아래 **배제대상 아님**.

관세청 목록통관 배제대상 12개 항목 (https://www.customs.go.kr/kcs/cm/cntnts/cntntsView.do?mi=2821&cntntsId=819):
의약품 / 한약재 / 야생동물 관련 제품 / 농림축수산물 등 검역대상물품 / 건강기능식품 /
지식재산권 위반 의심물품 / **식품류·주류·담배류** / **화장품(기능성·태반함유·스테로이드 함유·성분미상 등 유해화장품에 한함)** /
적재화물목록 정정 물품 / 통관목록 기재 부정확 물품 / 방송통신기자재(전파법 시행령 별표6의2 제1호 자목) / 세관장이 부적합하다고 인정한 물품

→ **인형(봉제 마스코트)·문구·의류·잡화는 배제대상에 없음 → 목록통관 가능.**
→ **과자·사탕 등 식품류는 전량 배제** (금액 무관 일반수입신고).
→ **화장품은 "일반 화장품"이면 목록통관 가능**, 기능성화장품 등만 배제. 배제되는 화장품은 미국발이라도 150불 이하만 면세 (「길라잡이」 p.10).
→ **지식재산권 위반 의심물품** 배제 조항 때문에, 정품이 아닌 굿즈(가품)는 목록통관 자체가 막힌다.

| 품목 | HS 코드 | 기본세율 |
| --- | --- | --- |
| 봉제 마스코트/인형 (동물·비인간 캐릭터, 속 채운 것, 방직용 섬유) | 9503.00-3411 | **8%** |
| 사람모형 인형 (방직용 섬유) | 9503.00-2110 | **8%** |
| 그 밖의 완구·피규어·퍼즐 전반 | 9503.00 전 호 | **8%** (9503호 하위 세번 전부 8%) |
| 볼펜·마커·만년필·샤프 등 필기구 | 9608 전 호 | **8%** |
| 의류 | (관세청 예시) | **13%** |
| 부가가치세 | — | **10%** |

계산 순서 (「해외 직구 통관 길라잡이」 p.14):

```
관세     = 과세가격 × 관세율
부가가치세 = (과세가격 + 관세 + 개별소비세 + 주세 + 농특세 + 교육세) × 10%
```

굿즈(완구/문구, 관세 8%)에는 개별소비세·주세가 없으므로:

```
관세    = 과세가격 × 0.08
부가세  = (과세가격 + 관세) × 0.10 = 과세가격 × 0.108
총세액  = 과세가격 × 0.188   ← 완구·문구 실효 세부담 18.8%
```

의류(13%)면 총세액 = 과세가격 × 0.243.

관세청 예시 검산 (「길라잡이」 p.14): 의류 과세가격 200,000원 → 관세 26,000 + 부가세 22,600 = **48,600원**. 200,000 × 0.243 = 48,600 ✅

### 1-3. 합산과세

합산되는 경우 (https://www.customs.go.kr/kcs/cm/cntnts/cntntsView.do?mi=8457&cntntsId=2807, 「길라잡이」 p.5):

1. **하나의 B/L·AWB로 반입된** 과세대상물품을 면세범위 내로 분할해 수입통관하는 경우
2. **같은 해외공급자로부터 같은 날짜에 구매한** 과세대상물품을 면세범위 내로 분할 반입해 수입신고하는 경우

- 다른 날에 주문했더라도 **단일 화물운송장으로 묶여 들어오면 전체를 합산**해 150불(미국발 200불) 초과 여부를 판단한다.
- 합산해도 합계가 150불 이하면 과세되지 않는다.
- 150불 이하라도 합산 결과 「수입통관 사무처리에 관한 고시」 별표11 자가사용 인정기준을 초과하면 과세대상.
- 합산금액이 목록통관 기준금액을 초과하면 **목록통관 배제 → 정식수입신고 대상**.

**배대지에서 여러 주문을 한 박스로 묶는 것(합배송)은 곧 단일 AWB이므로 전부 합산된다.** 계산기에서 합배송 옵션을 다룬다면 이 규칙을 반드시 반영해야 한다.

## 4. 계산식

기호: `P` = 상품가 합계(¥, 세금포함), `Sjp` = 일본 내 배송비(¥), `W` = 실무게(kg),
`Rjpy` = 원/엔 환율, `Rusd` = 원/달러 환율, `Rcus_jpy`·`Rcus_usd` = 관세청 과세환율.

### 경로 A: 배대지(짐패스 일본 항공)

```
1) 일본 내 배송비
   Sjp = (P >= 11000) ? 0 : 지역별요금
        // 오사카센터 1045 / 도쿄센터 990 / 후쿠오카센터 1320

2) 물품가격 (면세한도 판정용 — 국제운임 제외)
   GoodsValue_JPY = P + Sjp
   GoodsValue_USD = GoodsValue_JPY * Rcus_jpy / Rcus_usd

3) 면세 판정
   면세 = (GoodsValue_USD <= 150) AND (목록통관 배제품목 미포함) AND (합산 대상 아님)
   // 합배송 시에는 같은 AWB에 실린 모든 물품의 GoodsValue 합계로 판정

4) 국제운임 (짐패스 일본 항공, 브론즈)
   Wb = ceil(W / 0.5) * 0.5              // 0.5kg 단위 절상
   Intl_JPY = (800 + 480 * Wb) * (1 - 등급할인율)

5) 세액
   면세면:  Duty = 0, VAT = 0
   과세면:  DutiableValue_JPY = GoodsValue_JPY + Intl_JPY      // 국제운임 포함
            DutiableValue_KRW = DutiableValue_JPY * Rcus_jpy
            Duty = DutiableValue_KRW * 0.08                     // 완구·문구 HS 9503/9608
            VAT  = (DutiableValue_KRW + Duty) * 0.10
            Tax  = Duty + VAT = DutiableValue_KRW * 0.188

6) 실구매가(원)
   Total_KRW = (P + Sjp) * Rjpy_card      // 카드 결제 환율 (실환율 + 카드 수수료)
             + Intl_JPY * Rjpy_agency     // 배대지 적용환율로 별도 결제
             + Tax
             + 기타(국내택배·보험·검수 등 부가서비스 — 미확인)
```

### 경로 B: 치이카와 마켓 직배송(Global-e/DHL)

```
1) Sjp = 0                                 // 일본 내 배송 없음
2) GoodsValue_JPY = P
3) 면세 판정: 동일 (150 USD)
4) Intl = DHL 요금 — 체크아웃 시점에만 산출됨 (상수화 불가)
5~6) 동일. 단 Global-e가 관세·부가세를 선결제받는지(DDP) 여부 미확인
```

### 손익분기 참고

`관세청 과세환율`을 실환율 8.769로 근사하면 면세 한도 150 USD = 150 × 1360.36 / 8.769 ≈ **¥23,270**.
즉 일본 내 배송비 포함 **¥23,000 언저리**가 실무 상한선. 이를 넘으면 전체 금액에 18.8%가 붙는다.
(실제로는 관세청 주간 과세환율로 판정하므로 여유를 둘 것)

## 5. 확인 불가

| 항목 | 상태 | 비고 |
| --- | --- | --- |
| 치이카와 마켓 한국행 국제배송비 요금표 | **확인 불가** | Global-e/DHL이 체크아웃에서 실시간 산정. 공표된 무게 구간 요금표가 존재하지 않음. Global-e API(merchantid=2544)에도 요금 데이터 없음. 실제 장바구니를 만들어 한국 주소로 체크아웃해야만 확인 가능 |

| 짐패스 부피무게 산정식 | **확인 불가** | "부피무게 면제 서비스" 이벤트가 존재하는 것으로 보아 부피무게 규정이 있으나 요금표 페이지에 산식 미기재 |
| 짐패스 검수·박스교체·보험 등 부가서비스 요금 | **미조사** | https://www.jimpass.com/agency/add-service/agencyCode/600 |
| 타배Japan 등 타 배대지 요금 | **미조사** | 이번 조사에서 확인하지 않음 |
| 관세청 주간 과세환율 (2026-09-16 적용분) | **확인 불가** | 관세청 1차 출처에서 직접 확인 실패. 짐패스 사이드바 표기값은 미국 1,416.87원/USD, 일본 9.12원/JPY 이지만, 같은 사이트의 "금주고시환율" 게시판 최신 글이 2026-06-05(6/7~6/13)자여서 **갱신 지연으로 보인다**. 실환율 대비 약 4% 높음 → 최신값 아님으로 판단 |

| 간이세율 적용 여부 | **확인 불가** | 관세법 제81조 간이세율이 특송물품에 적용되는지, 적용 시 세율이 얼마인지 1차 출처에서 확인 실패(law.go.kr 프레임 구조로 본문 접근 불가). 관세청 「길라잡이」 p.14의 예상세액 계산방법은 **일반세율(관세율+부가세 10%)** 기준으로만 설명되어 있어, 이 문서는 일반세율 기준으로 작성했다 |
