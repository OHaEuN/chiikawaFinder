# 6. 화면설계서

> **원칙:** 화면마다 머리말(제목 + 한 문장 설명)에 그 화면이 답하는 질문을 쓴다. 카드는 어디서나 같은 모양이고(이미지, 나라 태그, 재고 표시, 브랜드·날짜, 이름, 가격), 데이터의 한계는 그 화면 맨 아래 공지 상자에 적는다.

기준일 2026-11-11. 화면 ID는 S-번호. 문구는 배포본 그대로다. 캡처는 저장소 `docs/images/`에 있다.

## S-00 공통 요소

| 영역 | 요소 | 동작·규칙 |
|---|---|---|
| 사이드바(데스크톱) | 로고, 메뉴 8개(아이콘 + 이름), 커서 선택 | 현재 페이지는 경로 접두사로 켜짐. 홈만 정확히 일치할 때 |
| 상단바(폰) | 로고, 메뉴 버튼 | 메뉴를 펼치면 같은 8개 |
| 카드(굿즈) | 사진, 나라 태그(한국 분홍·일본 파랑), 재고 표시(품절이면 사진 흐림 + "품절", 발매 전이면 "발매 예정"), 브랜드 또는 콜라보 · 날짜(26.10.02), 한국어 이름, 가격 | 누르면 상세. 데스크톱에서 사진에 올리면 옆에 크게 |
| 카드(장소) | 사진, 유형, 나라 · 도시, 진행 중/종료, 비공식 태그 | 누르면 상세 |
| 카드(인물) | 이미지, 그룹, 이름, 종족 | 누르면 상세 |
| 태그 | 분홍(한국·품절·주의), 파랑(일본), 민트(구매 가능·무료·안전), 노랑(분류·재입고·유료·확인 필요), 라벤더(콜라보·비공식), 무색(종료·품절) | 색은 뜻마다 고정 |
| 필터 칩 | 하나만 고르는 칩(`aria-pressed`) | 오프라인·온라인 |
| 필터 드롭다운 | 여러 개 고르는 체크박스, 건수 표시 | 굿즈·계산기 |
| 공지 상자 | 화면 맨 아래 회색 상자 | 확인 시각, 예상치, 기록 시작일 |
| 출처 | 상세 맨 아래 URL 목록 | 굿즈·장소·인물 |
| 외부 링크 | 새 창, "↗" | 클릭 이벤트 |

## S-01 홈 (/)

목적: 10초 안에 사이트가 무엇을 하는지 알고 여덟 갈래 중 하나로 들어간다.

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 히어로 | 제목, 설명, 3D 캐릭터 세 명 | "치이카와 굿즈를 살 때 보는 곳. 오늘 뭐가 품절됐고, 원화로 얼마인지, 어디서 사면 되는지 매일 확인해 정리합니다." 캐릭터는 `ssr: false`, 받는 동안 얼굴 이미지와 로딩 표시. 누르면 반응(`hero_character_tap`) |
| 타일 8개 | 오늘의 변화 / 애니 어디서 봐 / 토벌 코스 / 직구 계산기 / 굿즈 신상 / 발매 · 재입고 / 인물 · 세계관 / 오프라인 지도 | 아이콘 + 제목 + 한 줄. 매일 바뀌는 쪽과 고정 쪽이 섞여 있다 |
| 변화 패널 | "{날짜} 치이카와 마켓에서 N건이 달라졌습니다 · 품절 N · 신상 N · 재입고 N" + "환율 X원/엔 · {판정} 자세히 보기 →" | 기록과 환율 판정이 있을 때만. 누르면 오늘 |
| 최신 굿즈 | 카드 8장 + "전체 보기 →" | 발매일 최신순 |
| 진행 중인 팝업 · 이벤트 | 장소 카드 4장 + "지도에서 보기 →" | 기간이 있고 진행 중인 곳만 |
| 인물 | 카드 8장 + "전체 보기 →" | |

## S-02 오늘의 변화 (/today)

목적: 어제와 달라진 것만 본다.

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 머리말 | 제목, 설명 | "매일 아침 치이카와 마켓 전체를 훑어 어제와 맞대 봅니다. 공식몰은 무엇이 품절됐는지 알려 주지 않고, 재입고 목록도 하루가 지나면 사라집니다. 그래서 그사이에 달라진 것만 여기에 모읍니다." |
| 환율 패널 | 오늘 환율(소수 둘째), 기준일, 스파크라인(최저·최고), 판정 문장, 1만 엔 예시, 계산기 링크 | "{N}일 전보다 엔이 X% 싸졌습니다/비싸졌습니다. 기록한 M일 중 K번째로 쌉니다." 색은 좋음 민트·나쁨 분홍·중간 회색 |
| 달라진 것 | "{M월 D일 (요일)}에 달라진 것 · N건" | 새로 올라온 상품(민트) / 다시 들어온 상품(노랑) / 품절된 상품(분홍). 각 6장 카드, 나머지는 "외 N건 더 보기"로 이름 목록 |
| 지난 기록 | 날짜별 접이식 10일 | 날짜, 건수 태그, 앞 3건 이름. 펼치면 이름 목록 |
| 빈 상태 | "기록을 모으는 중입니다" | 기록이 없을 때 |
| 공지 | "{N}일치 기록을 쌓는 동안 품절 N건, 신상 N건, 재입고 N건을 기록했습니다. 지금 보고 있는 상품은 N개입니다. 확인하는 때는 매일 06:00(KST) 한 번이라, 그사이에 들어왔다 나간 상품은 기록에 남지 않습니다." | |

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 머리말 | "굿즈 신상" / "치이카와 마켓, 대원미디어, 콜라보 브랜드의 최근 6개월 신상 굿즈입니다. 가격과 구매처, 품절 여부를 함께 볼 수 있습니다." + 데이터 기준일 | 기준일은 마지막 수집일 |

## S-06 직구 계산기 (/calculator)

| 영역 | 요소 | 문구·규칙 |
|---|---|---|
| 머리말 | "직구 계산기" / "담아 보면 최종 얼마인지 바로 나옵니다. 공구 환율을 넣으면 수수료가 얼마나 섞였는지도 보입니다." | |
| 1. 살 상품을 담으세요 | 검색, 분류·캐릭터 칩(5건 이상만), 후보 8건 + ← 이전 / 다음 →, 담은 목록(사진, 이름, 엔화, 수량 ±, 삭제), 모두 비우기 → 되돌리기 | 빈 상태 "위에서 상품을 검색해 담아 보세요. 굿즈 상세의 '계산기에 담기'로도 담깁니다." |
| 2. 조건을 맞추세요 | 적용 환율(원/엔, 실환율 칩 "{X} 실환율 · {날짜}", 공구 9.5 · 10 칩), 해외배송비(원), 나눠 낼 인원(명 ±), 국내 택배비(원), 품목(인형 · 문구 · 잡화 / 의류), "기본값으로" | 숫자 칸은 쉼표 표시, 커서 위치 유지. 칩 클릭 이벤트 |
| 3. 결과 | "1인 부담 {총액}", 상품 합계(엔), 일본 내 배송료(무배컷 미달 시), 상품값(원), 해외배송비 분담, 국내 택배비, 관세 · 부가세, 전체 금액. 실환율 대비 차액 원 · %. 면세 한도까지 남은 금액 또는 초과 안내 | "공구로 합배송하면 면세 한도는 상자 전체로 따집니다." 폰에서는 "결과 보기 ↓" |
| 공구가 열리는 곳 | 채널 5개 카드: 이름(링크), 보호 수준 태그, 설명, 확인할 것 | |
| 공지 | "세금은 예상치입니다. 실제 과세는 같은 날 들어온 다른 주문과 합산될 수 있고, 품목 분류에 따라 세율이 달라집니다. 개별 공구를 추천하지 않으며, 결제와 배송에 관여하지 않습니다." | |
