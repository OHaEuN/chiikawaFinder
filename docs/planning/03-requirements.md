# 3. 요구사항 정의서

> **범위:** 공식몰을 매일 수집해 변화를 기록하고, 한국어로 검색·계산할 수 있게 하며, 입문자용 고정 정보를 모은 정적 웹 사이트. 서버·DB·회원가입·알림 푸시는 없다.

기준일 2026-11-11. 우선순위는 P0(없으면 서비스가 아님), P1(첫 출시), P2(운영하며 추가). 상태는 지금 배포본 기준.

---

## 3. 만들지 않는 것

- 회원가입·로그인, 서버 저장(장바구니는 브라우저에만)
- 알림 푸시, 실시간 재고(하루 한 번 확인이 전부)
- 가품 판별(판정 근거 데이터가 없고 틀리면 금전 피해)
- 개별 공구 모집글(검증 없이 올리면 송금 유도 통로가 됨)
- 시세·리셀가(체결가 데이터 없음)
- 결제·배송 관여
- 광고
